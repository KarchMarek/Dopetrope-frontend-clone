# 🖥️ Dopetrope Frontend Clone (Multi-Section Layout)

A simplified frontend recreation inspired by the Dopetrope template from HTML5 UP. This educational portfolio project focuses on recreating the structure and visual design of a multi-section webpage using semantic HTML and CSS.

[🔗 View Live Preview](https://karchmarek.github.io/Dopetrope-frontend-clone/)

## 🚀 Tech Stack

- **HTML5** – Semantic page structure.
- **CSS3** – Custom styling, layouts, typography, and responsive design.

---

## 💡 What I Practiced

- **Semantic HTML** – Built a structured webpage using semantic elements such as `header`, `nav`, `main`, `section`, `aside`, and `footer`.
- **Multi-Column Layouts** – Created a two-column content layout with a main article and sidebar.
- **Navigation Design** – Styled a responsive navigation menu with active button states.
- **Reusable Components** – Built reusable content cards, buttons, sidebar widgets, and footer sections.
- **Typography & Spacing** – Recreated the visual hierarchy and spacing of the original template.
- **Responsive Design** – Organized the layout to adapt cleanly across different screen sizes.

---

## 🎯 Project Goal

The goal of this project was to recreate the overall appearance of the Dopetrope template while using only HTML and CSS.

The project focuses on:

- Building a responsive navigation bar.
- Creating a two-column article and sidebar layout.
- Designing reusable content sections and call-to-action buttons.
- Structuring a multi-section footer.
- Writing clean, semantic, and maintainable frontend code without external frameworks or JavaScript.
